# made-with-rive

Things I've built with [Rive](https://rive.app), each in its own folder with everything needed to run it and build on it.

| Sample | What it is |
|---|---|
| [spider-cursor](spider-cursor) | A cartoon spider that crawls after your pointer. Clicks, scrolls, moods, a web in the corner, and a macOS app that puts it on your desktop. |

Every sample is a Rive CLI project: plain RML, Luau scripts and assets you open with `rive`. Install the CLI with:

```sh
curl -fsSL https://releases.rive.app/cli/install.sh | sh
```

Then run a sample from its folder with `rive .`.
